Daily monitoring model

GitHub Actions can run once daily for sources with a confirmed, accessible RSS/Atom feed URL. The starter registry intentionally leaves feed URLs blank unless you configure and test them. Websites without permitted feeds or APIs remain available through official links and manual import.

Legal safeguard: collected items are unverified leads. Confirm the underlying official document, applicability, effective date, amendments, stays and subsequent judicial treatment before taking action.

Deployment

Use the included README, SQL schema and GitHub Actions workflow. Daily automation runs only for registry entries with an explicitly configured feed URL. Add GitHub repository secrets for Supabase URL and service-role key to enable the scheduled collector. The service-role key must remain a GitHub Actions secret and must never be exposed to the browser.
